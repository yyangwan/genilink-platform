# 机会任务与行动修订页面接入

本轮在已确认的 v3 原型上接入 A05/E01 后端能力。设计依据为 `docs/prototypes/citation-intelligence-v3/README.md`、`value.js` 的机会卡片/抽屉/行动修订流程，沿用既有颜色、下拉、Tab、按钮和 ReadingDrawer。没有修改原型或另起一套页面样式。

## 已实现

- `/intelligence?view=actions` 直接呈现任务工作台，移除旧的重复简介及隐藏在折叠区的创建/审批入口。
- 机会按自有品牌、对比对象、平台和场景定位；任务准备状态与冻结/当前偏好排序预览分开。无关对象、失效选择与没有匹配结果明确提示，不静默换成第一个品牌。
- 同一观察同时匹配平台/比较对象/场景；分页读取全部已保存机会后再筛选，避免只筛前一页。多平台任务查看时保留全部子目标、各自原问题、维度、观察、反证及条件，不拼接问题，也不把检索候选改称实际引用。
- 交付对象、受众确认状态、提纲、验收、渠道理由、我方事实和材料需求分层。缺材料不代表缺能力；不适用或没有完整任务包的线索不提供创建执行计划按钮。
- 保存后及时显示对应的创建/批准/修订结果，定位到任务详情并移动键盘焦点。点击控件有指针，禁用和键盘焦点状态明确。
- 创建、具名批准、修改交付/提纲/验收、保留或移除已选事实、显式选用同任务新诊断、版本冲突、相关依赖差异和历史批准接入真实后端 API。新修订不会继承原批准；原文读取使用原 Run 和真实 owner/segment，按 Unicode 字符范围定位。
- 保存结果不确定时保留同一完整请求及幂等键；成功写入但读取失败不再次提交。旧版本编辑在冲突后锁定，不能自动套入新版。
- 材料入口保留项目/分析/行动深链，来源页提供返回原行动；旧“优化建议”页面引导到同一工作台，不维护另一个创建入口。
- 新 BFF 固定可信项目、写角色和计划审批范围，拒绝调用者注入身份/发布权限/跨项目证据，GET 不同步配置或写队列，写入前同步项目配置。

- 完整 `npm run release:check` 通过：依赖安装、Prisma 生成、类型、lint、全量测试、Next.js 生产构建。日志：本地 `E:/workspace/.citation-value-preview/tasks-release-final.log`。第一次全量仅因旧建议页测试仍查找已移除的创建按钮失败，已改为核对统一入口、平台范围及无写入；未放宽权限。
- 客户端虚构 TaskPack 经真实后端 `TaskPackV2` 和 `RevisionRequest` 校验，保留两个平台目标、一个原问题及精确 Unicode 引文。未调用模型、真实 OSS 或生产服务。
