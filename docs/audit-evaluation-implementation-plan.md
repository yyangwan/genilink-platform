# 品牌审计评价与竞争诊断实施计划

基线：已确认的 citation-intelligence-v1 原型。保持现有导航与视觉体系，在其上增强评价、证据、行动能力。范围为云端及客户页面，不包含设备网关发布。

**页面确认约束（2026-10-22）：任何布局、控件位置或样式调整，必须先更新原型并获得用户确认，再实施到业务页面。上一轮已经在本地调整的采集入口位置也须补原型确认，尚不可发布。本轮只推进后端与数据契约。**

## 阶段一：规则与采集体验

- [x] 客户采集默认一次；接口省略 rounds 时使用 1，明确传入其他值时拒绝，避免重复消耗额度。
- [x] 可见性页面顶部常驻采集范围和主按钮，放在进度之前；提示词选择可折叠。
- [x] 审计洞察移除采集创建与轮次设置，保留已有任务进度。
- [x] 当前任务状态未确认或采集中禁用创建；保留网络失败后的幂等重试。
- [x] 固定评分规则 v1 与单样本纯函数及测试，尚未接入真实报告。
- [ ] 页面交互验收与完整发布检查。

评分固定为出现 30%、推荐强度 30%、推荐位置 20%、选择理由 20%。推荐强度按 0–4 档映射为 0/25/50/75/100。明确排序列表的位置按 (列表长度−排名)/(列表长度−1) 计算，单项列表为 100；无排序不推断名次。理由为无/泛化/具体/对应需求，映射 0/25/75/100。正面情绪不代替总分。

完全分析且确认未出现为零分；采集失败、身份不明、未分析为未知。品牌预设型问题不进入竞争总分。任一维度未知不重分权重，不输出完整总分。出现品牌须有证据引用。此计算模块是评分基础，不能当作已上线评分功能。

## 阶段二：后端提取、持久化与报告契约

- [x] 核对服务归属：审计分析在 `geo-visibility-analyze/backend`，不是 ContentOS；后者负责内容创作。
- [x] 现有分段语义提取增加品牌推荐档位、显式排名、理由等级与逐字证据，提取流水线升级到 citation-intelligence-11，隔离旧缓存。
- [x] 推荐信号持久化到 SemanticCache.result，按回答/平台/段落投影到 IntelligenceRun.summary.brand_signals；使用现有 JSON 字段，不新增数据库迁移。
- [x] 门户 EvidenceRun 增加版本化信号类型，不修改业务页面或接入未经确认的展示。
- [ ] 新增完整版本化评分契约；当前 brand-signals-v1 仅为片段级提取，不是完整评分。
- [ ] 冻结每次审计的提示词意图、竞争问题资格、场景权重、平台权重及预期样本集合。
  - [x] 分析 manifest 保存所有计划样本（包括未完成样本），按平台/既有问题分类/问题等权冻结；同题同平台仅取一个独立样本，技术重试不增加权重。
  - [x] 后续修订沿用该审计已有 cohort，提示词或品牌名单变化不改变原分母。
  - [x] 竞争问题资格审核后端：全量问题审核、实名记录、乐观版本、幂等、权限验证；审核形成新 cohort 哈希并在后续修订使用，保留原分母和旧报告。门户代理已接通，尚无页面入口。
  - [ ] 业务场景分类：当前分类只是已有 category。审核页面需先更新原型并获确认；尚未确认的问题标记 needs_review，不发布竞争总分。
- [ ] 提取逐回答逐品牌推荐档位、显式排序、选择理由、顾虑、证据段落；全量品牌进入实体识别与消歧。
- [ ] 保存规则版本、提取版本、响应/段落/快照 ID、原始判定、各维度得分、覆盖情况和不可判定原因；分析修订不可覆盖历史结果。
- [ ] 采用相同样本集比较品牌，按冻结的平台及场景权重聚合；不静默归一化缺失平台。缺失总分只展示分项和覆盖，不排名。
  - [x] 后端固定评分纯函数及聚合函数：未知项保留原权重，覆盖或资格不足返回空总分。
  - [x] 整段回答分项汇总进入 summary.brand_evaluation，要求段落连续覆盖全文，身份确认；跨片段判定冲突保留未知，回溯信号 ID。
  - [x] 完整推荐列表保守验证：明确推荐顺序、连续编号、所有条目绑定不同品牌证据；无序、缺项、重复列表不计排名分。分项证据仍标记模型提取、未人工复核。
  - [x] 审核后的同一 cohort 接入各品牌总分，缺失样本、不完整分析或未确认身份保留未知；不输出无依据分数。
  - [x] 平台、既有问题类别、平台×问题类别的分项总分/四维分项；每个范围使用计划样本分母，缺失观察不被重新分配权重。
  - [ ] 真实业务场景分类、真实数据校准与客户展示。
- [ ] 同题同平台技术重试只采用一个有效样本；补采及重新分析不能重复计数。
- [ ] 来源覆盖、观点证据支持、事实正确性独立诊断；未知事实不扣品牌分。

验收：固定人工标注样本覆盖缺失、歧义、否定、无序推荐、品牌引导问题、跨平台与技术重试；同样输入重复计算结果一致，每个评分可回到证据。

## 阶段三：六维竞争诊断与页面

- [ ] 固定维度：场景覆盖、推荐竞争力、品牌认知、来源渠道、观点证据、平台差异。
  - [x] 首批竞争差距：出现、推荐强度、推荐位置、选择理由四项，在同平台×同问题类别中对比自有品牌与身份已确认的竞品/新发现品牌。
  - [x] 每条差距返回双方分数、相同样本范围、支撑问题/回答/证据，以及内容任务、材料、验收和后续同题同平台复测目标。
  - [ ] 来源渠道、观点支持/事实偏差与上述竞争差距贯通；当前不能称六维诊断完整实现。
- [ ] 审计洞察展示本次结论、分数和覆盖、前三项差距、优先行动；不展示伪造示例分数。
- [ ] 品牌发现对比支持自有、登记竞品、新发现品牌及分项证据。
- [ ] 平台差异对照定位同题差异，建议必须绑定实际平台证据，不能使用预设平台偏好。
- [ ] 来源文章与观点证据页面承接差距卡片的原文追溯。

验收：每条差距明确样本范围与双方分母、证据、缺失项；没有可比较数据时不能产生“我方落后”的结论。

## 阶段四：行动闭环与复测

- [ ] 行动必须包含差距、竞品证据、事实/假设区分、目标内容、材料、负责人、交付与验收条件。
- [ ] 按业务重要性、差距、证据充分度、成本排序；证据不足进入待验证。
- [ ] 后续独立审计固定问题、平台与规则版本，展示变化及可比性；单次快照不推断稳定性或因果。
- [ ] 与现有行动计划、内容创作及复测契约贯通，保留审批机制。

## 发布与当前约束
