# 品牌可见性分析页面原型 v1

日期：2026-10-13。对应 docs/designs/citation-intelligence-and-brand-growth.md 的全量内容、开放品牌发现、来源持久化、证据对齐及平台差异分析方案。

打开 gallery.html 查看全部页面原型图；打开 index.html 浏览可点击原型。两者均可直接用浏览器打开本地文件，无需安装或启动平台。

## 本版页面

1. 审计洞察：分析概览、来源覆盖、三个优先事项及后续流程入口。
2. 平台差异对照：同题同轮的三平台结果、来源与独立建议。
3. 品牌发现对比：全部实体、重点品牌、候选竞品确认、无品牌内容洞察。
4. 来源文章库：正文状态、品牌覆盖、来源与证据发现。
5. 观点与证据：逐平台回答与原文对照、支持/冲突、后补版本、事实/假设/缺失。
6. 优化行动：共性/专项筛选、修改资产、所需材料、平台复测目标、核实任务分流。
7. 内容创作方案：证据 Brief、确认事实、限定条件、审核与平台目标。
8. 行动效果复测：共同有效样本、平台表现差异、执行状态和待判断效果。

额外图片：evidence-parameter.png 为千问旧参数冲突状态；evidence-mobile.png 为390px移动端证据布局。

本轮未单独重画未改动模块。网站分析的新增目标页面和修改任务在行动卡及内容方案中呈现；趋势/战略分析的新增平台效果在复测页呈现。现有通用网站检查、品牌录入、内容编辑器及发布设置不展开。

## 示例与交互范围

全部品牌、文章、指标和历史节点均为虚构示例。当前审计示例为174/180条有效回答，来源72篇；全文54、部分6、受限8、待处理4。复测页为独立试点状态，不能与待办列表的执行状态混用。

支持导航、三平台证据切换、原文示例弹窗、品牌身份确认、重点名单切换、来源状态/搜索筛选、任务详情展开、创建方案草稿与观察窗口切换。不会调用后端、真实采集、发布或创建ContentOS业务记录。采样轮次和观察窗口仅演示选择状态，实际样本仅提供一组。交互状态仅在当前浏览器页面内保留。
