## 本轮确认范围

| 页面 | 需要确认的变化 |
|---|---|
| 可见性分析 | 明确的单次采集主按钮、阶段状态、回答与来源分开计数；不展示采集端选择 |
| 审计洞察 | 比较范围、样本结论、七类就绪条件、可执行机会；没有发起采集入口 |
| 品牌发现对比 | 保留身份确认；未登记主体和本次未提及的关注品牌；四维雷达与明细 |
| 平台差异对照 | 平台分别比较，保持场景；证据按原始品牌和平台展示 |
| 来源文章库 | 文章归并、逐次实际引用/候选区分；我方材料单独核实和批准事实 |
| 观点与证据 | 观察事实、来源支持程度、原因假设及我方材料明确分层 |
| 优化行动 | 修改对象、具体交付、验收、负责人、批准、新修订与材料补齐 |
| 内容创作方案 | 诊断证据与我方批准事实分开；人工任务/待审草稿、交付、发布登记 |
| 行动效果复测 | 一次同题观察、条件与时序预检；逐问题平台的描述变化 |

下拉框、文字按钮、页内切换、悬停指针、键盘焦点和抽屉沿用同一套视觉规则。示例状态可切换为“结果可用 / 问题待审核 / 分析失败”。

## 建议评审路径

1. 洞察 → 品牌对比 → 平台差异，切换比较范围并核对上下文。原型没有准备相应证据时显示明确空态，不给原文换品牌或平台标签。
2. 来源文章库 → 我方材料与事实 → 实施案例 → 核实材料 → 填写依据并批准事实。
3. 对应行动 → 审核批准 → 内容方案 → 人工交付 → 发布登记 → 一次同题观察。
4. 回到行动预览材料更新，创建新修订并重新批准。新修订不能继承旧发布记录。

## 演示边界

- 全部品牌、文章、分数和引文均为虚构示例，不能用来评价真实品牌或平台。
- 状态只在当前页面内存中模拟，刷新后重置；比较范围保存在 URL。没有数据库持久化、真实抓取、模型分析、内容生成或发布。
- 仅为部分比较范围准备机会示例，空态不代表真实业务没有机会；分数也是演示值，不能作为模型质量验收依据。
- 未知不填零，不闭合缺轴雷达；单轮差异不输出显著性或行动因果结论。
- 原型已确认不代表正式页面已经接入或发布。确认结果记录在执行任务清单的 `approvedPrototypeVersion`。
